# Project Documentation Rules (Non-Obvious Only)

- This repo has NO source files yet — it is a green-field project with only a pre-populated `.venv`.
- The project name is **passline** but the only content clue is the venv packages (Google ADK, FastAPI, Pydantic v2, Gemini).
