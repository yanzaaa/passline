# Passline Mission 04 — Corpus, Corruption Engine, Golden Fixtures

## Overview

Three deliverables:
1. **Asset fetch script** — downloads Blender open-movie SRT files; runs once; never in CI
2. **Corruption engine** — deterministic defect injector callable from CLI and programmatically
3. **Golden corpus** — committed clean + broken + manifest fixture sets, regenerable with one command

All corruptions operate through the existing `SubtitleCue` / `write_srt` pipeline so
broken files remain structurally valid parseable SRT. Defects are content-level only.

## Thresholds (canonical, single source of truth in the engine)

| Defect type | Threshold | Source |
|---|---|---|
| `cps_blowout` | CPS > 20.0 | `SubtitleCue.cps` computed property |
| `line_overflow` | line chars > 42 | `SubtitleCue.char_counts[i]` computed property |
| `three_line_cue` | `len(cue.lines) > 2` | structural |
| `short_duration` | `duration_ms < 1000` | `SubtitleCue.duration_ms` |
| `overlap` | `cue[i].end_ms > cue[i+1].start_ms` | timing comparison |
| `meaning_swap` | N/A (language-level) | substitution list |

### Sub-Task 2 — Corruption Engine

**Intent:**
`passline/corpus/corrupt.py` is the single source of truth for defect injection.
It is callable from the CLI (`python -m passline.corpus.corrupt ...`) and
programmatically (`from passline.corpus.corrupt import corrupt_file`).

**Core API:**
```python
@dataclass(frozen=True)
class DefectSpec:
    """Describes one injected defect for the manifest."""
    cue_index: int            # 1-based index matching SubtitleCue.index
    defect_type: str          # e.g. "cps_blowout"
    rule: str                 # the rule name the QC engine will check
    threshold: float          # the limit that was exceeded
    measured_value: float     # actual measured value after injection
    severity: str             # "ERROR" | "WARNING"
    category: str             # "DETERMINISTIC" | "MEANING_LEVEL"
    detail: str               # human-readable description

@dataclass(frozen=True)
class CorruptionResult:
    broken_file: SubtitleFile    # the mutated SubtitleFile
    broken_bytes: bytes          # write_srt(broken_file) — structurally valid SRT
    manifest: CorpusManifest     # full manifest with all DefectSpecs

@dataclass(frozen=True)
class CorpusManifest:
    schema_version: str          # "1.0"
    corpus_version: str          # "1"
    language: str
    source_file: str
    seed: int
    defects: list[DefectSpec]    # ordered by cue_index

def corrupt_file(
    source: SubtitleFile,
    seed: int = 42,
    defects: set[str] | None = None,   # None = all; subset = only those types
    language: str = "und",
    source_filename: str = "",
) -> CorruptionResult:
    ...
```

**Determinism contract:**
- Uses `random.Random(seed)` — NOT the global `random` module — so it is safe to call
  from multiple threads/coroutines and from tests without affecting other randomness.
- Same seed + same input file → byte-identical output, always.

**Per-defect implementation notes:**

**`cps_blowout`** — find cues with `total_chars >= 10` and `duration_ms >= 500`.
Shrink `end_ms` to `floor(total_chars / 22.0 * 1000) + start_ms`.
The divisor 22.0 (> threshold 20.0) guarantees CPS > 20.
Verify: `SubtitleCue(..., end_ms=new_end).cps > 20.0` — assert this in tests.
Pick 2–3 candidate cues per file.

**`line_overflow`** — find cues with exactly 2 lines where `sum(char_counts) > 42`
(i.e., joining them would overflow). Produce a single-line cue by joining with a space.
`new_line = " ".join(original_lines)`.
Verify: `SubtitleCue(..., lines=[new_line]).char_counts[0] > 42`.
Pick 1–2 candidates per file.

**`three_line_cue`** — find a cue with 1 or 2 lines. Add a third line by splitting
the longest existing line at a word boundary roughly in half.
Original: `["Line one text", "Line two text"]`
After: `["Line one", "text", "Line two text"]` (split first line at midpoint word).
The manifest records `len(cue.lines) == 3` as the measured value.

**`short_duration`** — find cues with `duration_ms >= 2000`. Set `end_ms = start_ms + 400`.
Verify: `SubtitleCue(...).duration_ms < 1000`.

**`overlap`** — for a pair of adjacent cues, set `cue[i].end_ms = cue[i+1].start_ms + 500`.
The `measured_value` in the manifest is the overlap amount in ms (500 in this example).

**`meaning_swap`** — apply per-language word substitutions from `substitutions.py`.
Substitutions must not change the character count by more than 20% to keep the
corruption realistic. Category = `MEANING_LEVEL`, not `DETERMINISTIC`.

**Candidate selection strategy:**
- Use `rng.sample(candidates, k)` for reproducible selection.
- Never apply multiple defects to the same cue (makes grading unambiguous).
- Apply defects in cue-index order (lowest index first).

**CLI interface:**
```
python -m passline.corpus.corrupt \
    --input tests/corpus/clean/tos-en.srt \
    --output tests/corpus/broken/tos-en-broken.srt \
    --manifest tests/corpus/manifests/tos-en-manifest.json \
    --seed 42 \
    --language en
```

### Sub-Task 4 — Corpus Generation Script

**Intent:**
`scripts/generate_corpus.py` reads clean files, runs the corruption engine, and
writes `broken/` and `manifests/` deterministically. One command regenerates everything.

**Command:**
```bash
python scripts/generate_corpus.py --seed 42
```

**Output:**
- `tests/corpus/broken/tos-{lang}-broken.srt` (written via `write_srt`)
- `tests/corpus/manifests/tos-{lang}-manifest.json`
- Prints a table: language, cue count, defect count, byte size

**Important:** The script imports `passline.corpus.corrupt` and `passline.io.srt`.
It does NOT download files — it assumes clean files are already in `tests/corpus/clean/`.
If a clean file is missing, it prints a clear error and skips that language.

### Sub-Task 5 — Golden Corpus Tests

**Intent:**
`tests/test_corpus.py` — the corruption engine's own test suite, running entirely
against committed fixtures (no network). Tests must use the cue model's own computed
properties to verify thresholds.

**Test groups:**

**Group A — Defect-type unit tests** (using synthetic cues, not corpus files):
Each test creates a minimal `SubtitleCue`, applies the corruption function,
and asserts the defect using the model's computed property.

- `test_cps_blowout_exceeds_threshold`:
  Build a cue with known text and duration. Apply CPS blowout.
  Assert `mutated_cue.cps > 20.0` (using `SubtitleCue.cps`).
- `test_line_overflow_exceeds_threshold`:
  Build two-line cue. Apply line join. Assert `mutated_cue.char_counts[0] > 42`.
- `test_three_line_cue_has_three_lines`:
  Apply three-line split. Assert `len(mutated_cue.lines) == 3`.
- `test_short_duration_under_threshold`:
  Apply short duration. Assert `mutated_cue.duration_ms < 1000`.
- `test_overlap_applied`:
  Assert `cue_i.end_ms > cue_i_plus_1.start_ms`.
- `test_meaning_swap_changes_text`:
  Assert text changed, category == "MEANING_LEVEL".

**Group B — Round-trip tests** (using committed broken corpus files):
- `test_en_broken_round_trips`:
  `write_srt(parse_srt(broken_en_bytes)) == broken_en_bytes`
- `test_fr_broken_round_trips`
- `test_de_broken_round_trips`

**Group C — Manifest correctness tests** (using committed manifests):
- `test_manifest_defects_match_broken_file`:
  Parse broken file. For each DETERMINISTIC defect in manifest:
  look up the cue by index and assert the violation using the model's computed property.
  - `cps_blowout` → `cue.cps > 20.0`
  - `line_overflow` → `any(c > 42 for c in cue.char_counts)`
  - `three_line_cue` → `len(cue.lines) > 2`
  - `short_duration` → `cue.duration_ms < 1000`
  - `overlap` → `cues[i].end_ms > cues[i+1].start_ms`
- `test_manifest_cue_indices_in_range`:
  Every defect `cue_index` is a valid index in the parsed broken file.
- `test_manifest_category_split`:
  Every defect has either `DETERMINISTIC` or `MEANING_LEVEL` category.

**Group D — Determinism tests**:
- `test_same_seed_produces_identical_output`:
  Call `corrupt_file(file, seed=42)` twice, assert both `broken_bytes` are equal.
- `test_different_seed_produces_different_output`:
  Call with seed=42 and seed=99, assert `broken_bytes` differ.
- `test_corpus_regeneration_matches_committed`:
  Run `corrupt_file` on committed clean files, assert the output matches committed
  broken files byte-for-byte. This is the hard verification that committed corpus
  is in sync.

**Group E — Defect toggling tests**:
- `test_disable_single_defect_type`:
  Run with `defects={"cps_blowout", "line_overflow", ...} - {"meaning_swap"}`.
  Assert no `meaning_swap` defects in manifest.
- `test_enable_single_defect_type`:
  Run with `defects={"cps_blowout"}`. Assert only `cps_blowout` defects in manifest.

## Implementation Notes

### Why `SubtitleFile` is frozen / `model_copy` pattern
`SubtitleFile` and `SubtitleCue` are `frozen=True`. The corruption engine builds
**new** `SubtitleCue` instances with modified fields using the `SubtitleCue(...)` constructor,
then assembles a new `SubtitleFile(cues=[...], srt_dialect=SrtDialect())`.
Never mutate existing cue objects.

### SrtDialect on broken files
Broken files produced by the corruption engine are new programmatic files.
Set `srt_dialect=SrtDialect(trailing_blank=True)` so they round-trip cleanly.

### Manifest is JSON, not JSONL
The manifest is a single JSON document (not JSONL), because it is a self-contained
analysis artifact — not a streaming event log.
